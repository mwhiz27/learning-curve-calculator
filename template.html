Learning-Curve Calculator

Fits the experience curve Cost(N) = Cost(1) × N−b to unit costs pulled from SEC EDGAR filings. N = cumulative units from the start of the data window, not lifetime production.

Log-log plot: unit cost vs cumulative units

Both axes are logarithmic. A true power curve plots as a straight line; a downward slope is learning, an upward slope means unit cost rises with volume.

Interpretation

Is the result robust? Every window × cost basis

Same fit rerun on each data window and cost basis with your current exclusions. If the sign of b flips or R² swings across rows, no single number deserves trust.

Method and limitations

Run it on another ticker

SEC EDGAR's API is free and needs no key, but it doesn't allow browser requests from other sites (no CORS), so fresh data is fetched with the included Python script and loaded here with Load data file:

python3 fetch_edgar.py AAPL --price 900 --price-source "Company-disclosed ASP, 10-K FY2016" # writes data/AAPL.json: quarterly COGS and revenue from XBRL, Q4 = FY − Q1..Q3

Source code: github.com/mwhiz27/learning-curve-calculator. extract_tko_ufc.py rebuilds the TKO dataset from the filings, with cross-filing consistency checks.
